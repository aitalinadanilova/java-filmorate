# Filmorate — Социальный сервис для оценки фильмов

![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)
![Spring](https://img.shields.io/badge/spring-%236DB33F.svg?style=for-the-badge&logo=spring&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/postgres-%23316192.svg?style=for-the-badge&logo=postgresql&logoColor=white)

**Filmorate** — это бэкенд-приложение для работы с рейтингами фильмов и поиском единомышленников. Сервис позволяет пользователям добавлять фильмы в базу, ставить лайки и формировать списки друзей.

## 🛠 Технологический стек
*   **Язык программирования:** Java 11/17
*   **Фреймворк:** Spring Boot (Spring Web, Spring JDBC)
*   **База данных:** PostgreSQL
*   **Сборка:** Maven
*   **Контроль версий:** Git (Командная работа через GitHub)

## 🤝 Командная разработка и функциональность
Проект реализован в составе команды, где я отвечала за проектирование архитектуры данных и ключевые модули взаимодействия.

**Ключевые возможности:**
*   **Проектирование БД:** Разработана нормализованная схема БД для хранения данных о фильмах, пользователях, жанрах и возрастных рейтингах (MPA).
*   **Система лайков и рейтингов:** Реализована логика формирования ТОП-фильмов на основе активности пользователей.
*   **Социальные связи:** Добавлен функционал работы с друзьями (добавление, удаление, поиск общих друзей).
*   **Кастомная валидация:** Реализованы аннотации для проверки корректности вводимых данных (дата релиза фильма, отсутствие пробелов в логине).
*   **REST API:** Спроектированы и реализованы эндпоинты в соответствии с REST-принципами для удобной интеграции с фронтендом.
